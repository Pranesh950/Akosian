What is Akosian?

Akosian is a free, open-source health tracker for sleep, recovery, strain, food, and habits. It runs on your phone, not someone else's server — no account, no subscription, no telemetry. The optional coach can use your own API key or a model running entirely on-device.

Privacy, plainly

Your data stays on your phone

Akosian has no backend, no login, and no crash reporter. Scores, food search, journaling, and on-device AI work with no network. Cloud AI is optional and goes straight from your phone to the provider you picked.

  • No account, no email, no subscription
  • No telemetry or third-party SDKs
  • API keys in OS secure storage on your phone
  • Prompts scrubbed before any cloud request
In this browser demo

Everything you see is fake sample data. The OpenRouter key you paste stays in this tab's memory, is never saved to disk, and is sent only to OpenRouter. Reload the page and it's gone.

Honest limits

What the demo can't do

The real app is native for a reason. Here's the line between the demo and your phone.

No live health sync

HealthKit and Health Connect are native modules. The demo shows fake readings from a made-up day.

No camera barcode scanning

The scan button is here so you can see where it lives, but browsers can't open the in-app scanner. Install to scan.

No on-device model

Apple Foundation Models, Gemini Nano, and llama.cpp need the native build. Use an API key here.

OpenRouter only for real chat

Browser CORS lets OpenRouter work. Other providers show a notice; the phone app supports all four.
